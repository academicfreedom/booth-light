How will you use Booth Light?

▦ QR code · class hand-out

QR code opens the class hand-out page on the instructor’s Mac (http://127.0.0.1:8971). It works only while Start-Handout.command is running on that Mac; students on the same Wi-Fi scan the code to download Booth Light.

  1. Booth Light is one file, booth-light.html. Your instructor sends it as a zip (Canvas, email or the classroom hand-out).
  2. Unzip it and keep the file in a folder on your laptop. Open it by double-clicking: Chrome, Firefox or Edge.
  3. Opened from the disk, it makes no network connection: no website sends it to you, and it sends nothing.

Once Booth Light is on your Home Screen, open it in aeroplane mode (Wi-Fi and mobile data off). The phone then makes no network connection, so neither your network nor GitHub receives anything. If you open it while connected, the phone checks GitHub for an update, and that check is logged like your first visit. Your recordings, notes and texts are not part of that check: Booth Light never sends them. A file you export stays on the phone if you save it to On My iPhone.   1. Opening the page while connected: the phone asks the network for the address of the site (a DNS lookup) and starts an encrypted connection whose first message names the site in plain text (TLS SNI). The network (WWU Wi-Fi or your phone carrier) can log your device, your login on eduroam, the site name, the time and how much data moved.
  2. The network cannot read the page or anything you type or record: the connection is encrypted (https), and Booth Light sends none of it.
  3. GitHub logs your internet address, the time, the files requested and your phone and browser type. It receives no recordings.
  4. After you add it to the Home Screen, the phone keeps a copy (a service worker). Opened with no connection, it contacts nothing. Opened while connected, it checks GitHub for an update about once a day; each check is logged like the first visit.
  5. How long WWU and GitHub keep these logs, and who may obtain them, is set by WWU policy, Washington State law and GitHub’s terms. Booth Light cannot change that.
  6. The laptop file makes no network connection: none of this happens.

        5Who can hear this recording?

        In a time of increased surveillance, any copy of an interview that an institution or third party company holds can be requested by third parties, leaked, or sold. This app mitigates for that risk by keeping the recording on your device and by authorizing all contributors to decide who may access their stories at any time.

        Podcast co-producers and storytellers can select who may hear their podcast episodes in The Process Consent options below. Each person on the recording chooses the option that best suits their own risk assessment. The recording is shared only as widely as the most private choice. You can choose a codename, not a real name, if and when necessary.

        1 Nothing leaves your device.
        2 Only the instructor can hear it.
        3 Only students in this class can play it. It is listed nowhere public.
        4 In the Listening Room archive, anyone with the link can play it. There is no download button. The storyteller, the episode producer and the instructor can each erase it at any time.
        5 Listed and playable on the Listening Room front page. The storyteller, the episode producer and the instructor can each erase it at any time; a storyteller who withdraws consent erases it.

        Sovereign tech

        1. Recordings and notes are stored in this browser’s storage (IndexedDB) on this device. There is no account and no server, so no company holds a copy.
        2. Once open, the page makes no network requests. Nothing is sent to WWU, your instructor, Google, Apple, Microsoft or Spotify.
        3. A file leaves the device only when you press Export. It is saved to the folder you choose.

        Process consent

        1. Five permission levels, from 1 (this device only) to 5 (the Listening Room front page). The recording is shared at the most private level anyone on it chose.
        2. Each person gets an erase code. In the Listening Room Archive (not built yet), the storyteller, the producer and the instructor can each delete an episode without anyone else’s approval.
        3. Every record the app writes uses the codenames you type, not real names.

        Tap a person, then a level on the left.
